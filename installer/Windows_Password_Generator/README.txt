🔒 SecurePass for Windows

How to Use:
1. Extract the ZIP file to any folder on your computer
2. Double-click "SecurePass.bat" to run the application
3. If Python is not installed, download it from: https://python.org

That's it! The application will open with a graphical interface.

Features:
- Generate secure passwords with customizable length
- Choose character types (uppercase, lowercase, numbers, symbols)
- Copy passwords to clipboard
- Save passwords to local history

Requirements:
- Python 3.x (download from https://python.org)
- tkinter (usually included with Python)

If you get an error, make sure Python is installed and added to PATH.
